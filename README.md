# Weather App 🌤️

A responsive weather application that provides real-time weather information for any location using the OpenWeather API. Users can search for a city and get live weather details including temperature, humidity, and weather conditions.

## 🚀 Features

- Search weather information by city name
- Displays real-time temperature data
- Shows humidity and weather conditions
- Fetches live data using OpenWeather API
- Dynamic UI updates based on user input
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/abhi-pandey6/weather-app.git
```

2. Navigate to the project directory:

```bash
cd weather-app
```

3. Open `index.html` in any modern web browser.

4. Enter a city name and click search to view real-time weather information.

## 🌐 API Used

- OpenWeather API for fetching live weather data
